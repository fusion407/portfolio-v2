## Proposed implementation

Next.js App Router, React, TypeScript, Tailwind CSS, typed local content, and isolated interactive enhancements. The full dependency and component plan is in the discovery document. Exact versions and compatibility will be verified during the approved foundation milestone.

There are no application installation, development, build, or test commands yet. Those will be documented when the foundation is implemented. Current verification is limited to planning consistency, workspace inspection, official compatibility documentation review, and hash verification of the supplied source documents.

## Deployment boundaries

Development and eventual Netlify previews must stay isolated from the live portfolio. No production deployment, domain assignment, DNS change, or live Netlify configuration change is authorized. Production migration and the NeonSynth browser playground are separate future tasks.
